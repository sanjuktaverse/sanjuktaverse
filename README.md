### 💬 &nbsp;[Aspect-Based Sentiment Analysis for E-Commerce Reviews](https://github.com/)

<img src="https://img.shields.io/badge/⭐_FLAGSHIP_PROJECT-be185d?style=for-the-badge&labelColor=0d1117" />

A sentiment classification model built using **NLTK** and **scikit-learn** that categorizes e-commerce reviews as positive, negative, or neutral at the aspect level. Evaluated multiple ML algorithms, selecting **Decision Tree** for optimal performance — achieving a **98% accuracy**. Visualized sentiment distributions to derive actionable customer insights.

`Python` &nbsp;`NLTK` &nbsp;`Scikit-Learn` &nbsp;`Decision Tree` &nbsp;`Feature Engineering` &nbsp;`NLP`
