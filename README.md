### 🧠 &nbsp; Aspect-Based Sentiment Analysis
**for E-Commerce Reviews &nbsp;|&nbsp; Internship Project**

<br/>

Built and delivered during my industrial internship at **Ardent Computech × FIEM**. The goal was to go beyond simple positive/negative labels and understand *which aspect* of a product a customer was commenting on — pricing, quality, delivery, etc.

I collected and preprocessed a real e-commerce review dataset, applied NLTK pipelines for tokenization, stopword removal, and stemming, then engineered features that would carry aspect-level signal.

After benchmarking **Decision Tree, SVM, Naive Bayes, Logistic Regression, and Random Forest**, Decision Tree delivered the highest performance at **98% accuracy** with the most interpretable output — making it the right choice for a production-oriented system.

Results were visualized through sentiment distribution plots and confusion matrices to derive actionable insights for retailers.

<br/>

```python
# Model selection benchmark
models = {
    "Decision Tree"      : 0.98,   # ← selected ✅
    "Random Forest"      : 0.96,
    "Logistic Regression": 0.94,
    "SVM"                : 0.93,
    "Naive Bayes"        : 0.89,
}
best = max(models, key=models.get)
print(f"Best model: {best} @ {models[best]*100:.0f}% accuracy")
# Best model: Decision Tree @ 98% accuracy
```

### 🔌 &nbsp; Automatic Fall Detection & Alert System
**for Elderly Users &nbsp;|&nbsp; Live Project &nbsp;|&nbsp; C++ / IoT**

<br/>

A real-time wearable health monitoring and safety device designed for elderly users living alone or in assisted care. This was a **live project** — not a toy prototype.

The system fuses data from three sensors simultaneously: the **MPU6050 accelerometer/gyroscope** detects sudden orientation changes that indicate a fall; the **MAX30102** monitors heart rate and blood oxygen saturation (SpO₂) continuously; and the **NEO-6M GPS module** tracks the wearer's real-time location.

When a fall is detected, the system immediately fires an emergency alert with the user's GPS coordinates — no button press needed. All live data streams to a remote monitoring dashboard via **Blynk IoT**, letting caregivers or family members watch vitals in real time from anywhere.

The entire firmware was written in C++ on the ESP32 microcontroller, handling concurrent sensor reads, threshold-based event detection, and IoT communication without an RTOS.

<br/>

```cpp
// Fall detection core logic
void detectFall(float ax, float ay, float az) {
    float magnitude = sqrt(ax*ax + ay*ay + az*az);
    if (magnitude > FALL_THRESHOLD) {
        triggerAlert(getGPSLocation());
        notifyBlynk("FALL DETECTED");
        sendEmergencySMS();
    }
}
```

### 🎬 &nbsp; Movie Recommendation Engine
**Content-Based Filtering &nbsp;|&nbsp; TF-IDF × Cosine Similarity**

<br/>

A content-based recommendation system that takes a movie as input and returns a ranked list of the most similar movies based on their textual feature space.

The pipeline begins with preprocessing movie metadata — title, genre, cast, director, keywords — which are combined into a single rich text representation per movie. **TF-IDF vectorization** then converts these into high-dimensional vectors where each dimension corresponds to a vocabulary term, weighted by how distinctive it is across the corpus.

**Cosine similarity** is computed between the query movie's vector and every other entry in the database, producing a ranked similarity score. The top-N most similar movies are returned as recommendations.

The approach is lightweight, interpretable, and produces surprisingly relevant suggestions — because it learns from the *language used to describe* movies, not just categorical metadata.

<br/>

```python
# Core recommendation logic
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.metrics.pairwise import cosine_similarity

tfidf = TfidfVectorizer(stop_words='english')
tfidf_matrix = tfidf.fit_transform(movies['combined_features'])
cosine_sim = cosine_similarity(tfidf_matrix, tfidf_matrix)

def recommend(title, top_n=10):
    idx = indices[title]
    scores = sorted(enumerate(cosine_sim[idx]),
                    key=lambda x: x[1], reverse=True)
    return [movies['title'].iloc[i] for i, _ in scores[1:top_n+1]]
```
